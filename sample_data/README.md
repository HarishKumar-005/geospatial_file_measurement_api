# Sample Data

These small, fictional datasets support repeatable local testing and demonstrations of the Geospatial File Measurement API. Their coordinates are near Chennai, India, and they declare WGS 84 (`EPSG:4326`).

| File | Purpose |
|---|---|
| `polygon_area_demo.kml` | Polygon area measurement |
| `line_length_demo.kml` | Line length measurement |
| `point_features_demo.kml` | Point parsing; no area or length measurement should be produced |
| `mixed_geometry_demo.kml` | Polygon, line, and point features in one file |
| `shapefile_parcels.zip` | Zipped polygon Shapefile, including its companion files |

See [`../docs/SAMPLE_DATA_AND_TESTING.md`](../docs/SAMPLE_DATA_AND_TESTING.md) for usage instructions. Upload `shapefile_parcels.zip` as a ZIP file; do not extract it before uploading.
